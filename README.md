# NekoriGram Web

Первая версия Telegram-подобного веб-мессенджера: личные сообщения, группы, авторизация по
номеру телефона/логину, отправка сообщений в реальном времени через WebSocket.

## Запуск

```bash
npm install        # единственная зависимость — ws
./start-all.sh     # оба узла в фоне, логи в logs/
./stop-all.sh      # остановить
```

Оба узла работают с одной базой SQLite и общим `TOKEN_SECRET`, поэтому токен, выданный
одним узлом, принимается другим, а сообщения доходят до клиентов на любом узле.

| Хост            | Порт  | Назначение       |
|-----------------|-------|------------------|
| work-1          | 12000 | Основной узел    |
| work-2          | 12001 | Дополнительный   |

База данных (SQLite, WAL) хранится в `data/nekorigram.db`. Узлы пишут в один файл;
`db.js` повторяет инициализацию при блокировке, а `busy_timeout` сглаживает конкуренцию.

## Realtime между узлами

Каждый узел держит WebSocket-клиентов своего процесса. События чата передаются между
процессами через локальную мультикаст-шину (`bus.js`, UDP 239.255.77.77:12100), поэтому
клиент на work-2 сразу видит сообщение, отправленное на work-1. Шина работает в пределах
одной машины; для нескольких хостов нужен внешний брокер (Redis/NATS).

## Автозапуск

`cron` с заданием `@reboot /workspace/project/start-all.sh` поднимает оба узла после
перезагрузки. Скрипт идемпотентен: уже запущенный узел повторно не стартует.

## Конфигурация

| Переменная    | По умолчанию        | Назначение                          |
|---------------|---------------------|-------------------------------------|
| `PORT`        | 12000               | Порт узла                           |
| `HOST`        | 0.0.0.0             | Интерфейс прослушивания             |
| `DATA_DIR`    | `./data`            | Каталог базы данных                 |
| `TOKEN_SECRET`| генерируется        | Общий секрет подписи токенов        |
| `BUS_PORT`    | 12100               | Порт мультикаст-шины                |
| `BUS_GROUP`   | 239.255.77.77       | Мультикаст-группа шины              |

## Возможности первой версии

- Регистрация и вход по номеру телефона или @username
- Личные сообщения и группы
- Сообщения в реальном времени (WebSocket)
- Ответы на сообщения, редактирование, удаление
- Индикация «печатает…»
- Отметки о прочтении (✓ / ✓✓)
- Поиск по людям и чатам
- Тёмная тема в стиле Telegram Web

## Структура

```
server.js        HTTP API + WebSocket сервер
db.js            SQLite (node:sqlite) схема и хелперы
bus.js           Межпроцессная шина событий (мультикаст)
public/          Фронтенд (HTML/CSS/JS)
start-node1.sh   Узел 1 (:12000)
start-node2.sh   Узел 2 (:12001)
start-all.sh     Запуск обоих узлов, идемпотентно
stop-all.sh      Остановка узлов
data/            База данных (создаётся автоматически)
logs/            Логи узлов (создаётся автоматически)
```

## API

- `POST /api/auth/register` — создание аккаунта `{phone, first_name, last_name?, username?, password}`
- `POST /api/auth/login` — вход `{login, password}` (login = телефон или @username)
- `GET /api/users?q=` — поиск пользователей
- `GET|POST /api/chats` — список чатов / создание чата
- `GET|POST /api/chats/:id/messages` — история / отправка сообщения
- `POST /api/chats/:id/read` — отметить прочитанным
- `POST /api/messages/:id/edit` / `POST /api/messages/:id/delete`
- `POST /api/chats/:id/leave` — выйти из чата
- `WS /ws?token=` — realtime: `message`, `message_deleted`, `read`, `typing`
